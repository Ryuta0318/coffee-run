# COFFEE RUN

社内で「今からスタバ／マンモスコーヒー行くけど、みんなもいる？」を投稿し、メンバーが注文、投稿者が受け取り・立て替え、各自が PayPay で送金・投稿者が入金確認するまでを1つのWebアプリで完結させる。**注文の取りまとめを楽にし、支払い漏れをゼロにする。**

デザインの元（ハンドオフ）は `docs/handoff/` にあります（`Coffee Order v2.dc.html` が動くプロトタイプ）。見た目・文言・挙動はこれをそのまま移植しています。

## できること

- **名前だけで登録**（表示名・PayPay ID・アイコン色）。以後はその端末で自動ログイン
- **アイコンの写真**：アカウント画面で写真を選ぶと、まん中を正方形に切り取って 256px に縮めてから保存します（1枚300KBまで、JPEG・PNG・WebP のみ）。写真はログインしている人にだけ見せます。写真がない人は色＋頭文字
- **投稿**：店舗（スターバックス / マンモスコーヒー）・締切（15分単位の5択）・出発時間を選ぶ。投稿すると Slack・Teams 用の共有文がクリップボードにコピーされる
- **注文**：一緒に行ける！ / お願いします！、メニュー（スタバ24品・マンモス17品）、サイズ・温度（提供のない組み合わせは選べない）、カスタムメモ、「その他のドリンク」は自由入力。「いつもの」で前回と同じ注文
- **注文一覧**：同じ注文を自動集計した「オンライン注文用まとめ」とコピー、受付の締め切り／再開（投稿者のみ）
- **精算**：回収状況、PayPay ボトムシート（①送り先の ID をコピーして PayPay を開く → ②送金を報告）、投稿者の入金確認・取り消し、未払いの人へのリマインド
- **チャット**：定型文、Enter 送信（日本語入力の変換中は送らない）
- **リアルタイム**：投稿・注文・支払い状態・チャットは、ほかの人の操作がすぐ画面に出る（WebSocket）
- **プッシュ通知**（Web Push）：新しい投稿（投稿者以外）・締切5分前（全員）・送金の報告（投稿者へ）・リマインド（未払いの人へ）。通知をタップするとその投稿が開く
  - Android（Chrome）・PC はそのまま使えます
  - iPhone は Safari の共有ボタン →「ホーム画面に追加」して、そのアイコンから開いたときに使えます（iOS 16.4 以上）。フィードに案内が出ます
- **ホーム画面に追加**（PWA）・起動アニメーション（タップで飛ばせる。ヘッダーのロゴで再生）

## しくみ

ハンドオフの推奨は Next.js + Supabase + Vercel でしたが、**Cloudflare Workers 1つ**で作っています（DARA と同じ構成）。外部サービスのアカウントや鍵の設定が要らず、`wrangler deploy` だけで公開できます。

| ハンドオフの推奨 | このリポジトリ |
| --- | --- |
| Supabase Postgres | Durable Object の SQLite（`src/worker.js` の `init()` にテーブル定義） |
| Anonymous Auth（名前だけログイン） | 登録時に端末ごとのセッション（HttpOnly Cookie）を発行 |
| Realtime | Durable Object の WebSocket（Hibernation API）で変更を全員に配信 |
| Edge Functions + pg_cron（締切5分前） | Durable Object の Alarm。次に通知すべき時刻にだけ起きる |
| Web Push（VAPID） | `src/push.js`（WebCrypto だけで実装、DARA と同じもの）。鍵は最初に自動でつくってデータベースに保存 |
| RLS | サーバー側で同じルールを確認（下の「ルール」） |
| Next.js + Tailwind | Preact + htm（`public/vendor` に同梱、ビルド不要）。スタイルはプロトタイプと同じ値をインラインで |

```
src/worker.js       API・データ・リアルタイム配信・締切5分前の通知
src/push.js         Web Push（暗号化と VAPID 署名）
src/menu.js         メニューの初期データと店舗の情報（価格は参考値）
public/index.html   画面の入口（PWA）
public/app.js       画面（プロトタイプの全画面を移植）
public/style.css    hover・focus・アニメーション
public/sw.js        プッシュ通知を受け取る service worker
public/admin.html   メニュー管理
public/fonts/       Archivo Black（数字・タイマー用、SIL OFL）
scripts/make-icons.mjs  アプリのアイコンを書き出す
test/               テスト（下の「テスト」）
docs/handoff/       デザインのハンドオフ（参照用）
```

### ルール（サーバーで確認していること）

- 受付中 = `closed でない かつ 今 < 締切`。締切を過ぎると自動で受付終了。締切・再開は投稿者だけ（再開は締切前のみ）
- 1投稿につき1人1注文。再注文は上書き。注文すると「いつもの」（`last_orders`）を更新
- **金額はサーバーがメニューから決めて**、注文時点の値で保存（画面から送られた金額は使わない。メニューを改定しても過去の注文は変わらない）
- 支払い：`unpaid` →（本人が報告）`reported` →（投稿者が確認）`done`。`done` → `unpaid` に戻せるのは投稿者だけ
- 投稿者自身の注文は、自分で立て替えるので最初から「確認済み」
- 注文の削除は、投稿者はいつでも、本人は受付中だけ
- 投稿の削除は投稿者だけ（投稿詳細の「削除」）。注文・チャットもいっしょに消え、開いていた人はフィードに戻る
- 投稿には PayPay ID が必要

## ローカルで動かす

```sh
npm install
npx wrangler dev          # http://localhost:8787
```

メニュー管理を試すときは、`.dev.vars` に `ADMIN_TOKEN=（12文字以上）` を書いておきます。

## 公開

```sh
npx wrangler login
npx wrangler secret put ADMIN_TOKEN   # メニュー管理用（12文字以上）
npx wrangler deploy                   # https://coffee-run.<アカウント>.workers.dev
```

- 独自ドメインにするときは、`wrangler.jsonc` に `routes` を足します
- Web Push の連絡先は、公開URLが自動で使われます。メールアドレスにしたいときは `wrangler.jsonc` の `PUSH_SUBJECT` を `mailto:...` に

> **注意：URL を知っていれば誰でも登録できます。** 社内だけに限るなら、Cloudflare Zero Trust の **Access** で、このアプリの URL を会社のメールアドレスだけに制限してください（アプリの変更は不要）。

## メニューと価格の更新

価格は参考値です（スタバ：2026年2月改定時点、**10/9 改定予定** / マンモス：報道等ベースで一部推定）。

- **すぐ直す**：`/admin.html` を開き、`ADMIN_TOKEN` を入れて「読み込む」→ JSON を直して「保存する」。全員の画面にすぐ反映されます
- **コードで直す**：`src/menu.js` を書き換えて `MENU_VERSION` を1つ上げてデプロイすると、メニューが入れ替わります（管理画面での変更は上書きされます）

メニューの写真は使っていません（公式写真は各社の著作物のため）。許諾済みの画像があれば差し替えられます。

## 決めたこと・未確認のこと

- **PayPay で払う**：①は送り先の **PayPay ID をコピー**して、スマホでは `paypay://` で PayPay を開きます。PayPay の「送る」→ ID 検索に貼り付け、金額（画面に大きく表示・「金額をコピー」もあり）を入れて送金します。PayPay が入っていない端末では開けません（**実機での確認が必要**）。マイコードのリンクは有効期限があるため使っていません
- **ログアウト**すると、その端末ではもう同じアカウントに戻れません（名前だけのログインのため）。もう一度登録すると別の人として扱われます
- ハンドオフに画面がなかった部分は、同じ部品・色で足しています：通知をオンにする案内（フィード上部）、アカウント画面の通知のオン／オフ、接続が切れたときの帯
- アカウント画面の注記は「登録情報はこの端末に保存されます。」から「この端末では、次回から自動でログインします。」に変えています（データはサーバーで共有されるため）
- 「リマインド」は、プロトタイプどおり文面をコピーしたうえで、未払いの人にプッシュ通知も送ります（同じ投稿で1時間に6回まで）
- 投稿の一覧は新しい順に100件まで
